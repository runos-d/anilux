# Скрипт для замены домена во всех плеерах

## Описание

Скрипт предназначен для случая, если вам нужно будет максимально быстро сменить на сайте все домены плееров на другие.

Скрипт предназначен для тех плееров, которые вы добавляли на сайт в ручную. Если все плееры на вашем сайте отображаются с помощью скрипта для автоматического добавления плееров, то тогда вам этот скрипт не нужен.

Вы можете воспользоваться генератором скрипта, чтобы быстро настроить скрипт, либо можете почитать подробно про каждый параметр скрипта и настроить его вручную.

Скрипт по умолчанию заменяет все старые домены на актуальные. То есть вы можете его разместить как есть, не изменяя никакие настройки в конфигураторе.

---

## Генератор конфигурации

| Параметр | Значение |
| --- | --- |
| Дожидаться полной загрузки страницы перед срабатыванием | Да |
| Какие домены заменять (через запятую) | |
| На какой домен заменять (один домен) | |

**Копировать**

```html
<script>
  !function(e,n,t,r,a){r=e.createElement(n),a=e.getElementsByTagName(n)
  [0],r.async=!0,r.src=t,a.parentNode.insertBefore(r,a)}
  (document,"script","//kodik-add.com/change-domains.min.js");
</script>
```

---

## Параметры

| Название | Стандартное значение | Доступные значения | Описание |
| --- | --- | --- | --- |
| `fromDomains` | `["kodik.org"]` | `["example.com"]`, `["example.com", "example2.com"]` | Список доменов, которые нужно будет заменить скрипту |
| `toDomain` | `"kodikplayer.com"` | `"example.com"` | Домен (один), на который будут заменяться домены из предыдущего параметра |
| `onDomReady` | `true` | `true`, `false` | Дожидаться ли скрипту полной прогрузки страницы. Если этот параметр указан как `true` (стандартное значение), то скрипт можно поместить в абсолютно любое место на странице. Он в любом случае сработает. Но если вы хотите заменить плеер максимально быстро, то вам надо указать этот параметр в `false` и поставить сам скрипт сразу за кодом плеера (либо после него, но не до него). |

---

## Пример

**Копировать**

```html
<script type="text/javascript">
  var kodikChangeDomains = {
    fromDomains: ["example.com"],
    toDomain: "kodikplayer.com",
    onDomReady: true
  };

  !function(e,n,t,r,a){r=e.createElement(n),a=e.getElementsByTagName(n)
  [0],r.async=!0,r.src=t,a.parentNode.insertBefore(r,a)}
  (document,"script","//kodik-add.com/change-domains.min.js");
</script>
```
