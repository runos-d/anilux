Reminder связан с CalendarRelease; уникальность user/release обеспечивает повторяемое создание. follow_schedule обновляет время при merge_calendar. Явное изменение времени выключает перенос. Релиз без локального Anime допустим: тайтл связывается после появления в каталоге. Для сериала нужен известный номер серии.

notifications.process_episode_events объявлен в beat каждые 60 с. Устаревшее доказательство проверяет отдельная verify_calendar_episode (40/45 с, один запрос Kodik с connect/read 5/30 с). Отсутствие подтверждается после срока напоминания полным успешным ответом; ошибка, обрезанная выдача или неверные данные не вызывают задержку. На HTTP нет запроса провайдеру. Задержка не содержит ссылки на плеер; появление серии отправляет доступность и закрывает напоминание. Повторы и параллельная подписка используют EpisodeNotice.

Ручные reminder_time/повторы независимы от календаря. Поддержаны недельный/пользовательский интервал и end_date; новые повторения сохраняют локальное время по timezone_name через DST. Сайт/браузер используют NotificationService и существующий WS/browserNotifications; enable_push/enable_sound сохраняются. Закрытый сайт получает server Web Push через настроенную VAPID-пару и подписку устройства: send_push_for_notification отправляет шифрованный payload, учитывает настройки и обрабатывает истёкшие/временные ошибки. Реальная доставка проверена в Chrome и Edge 2026-10-13 (F0033).

Источники: `backend/apps/notifications/application/episode_events.py`, `episode_verification.py`, `celery_tasks.py`, `backend/apps/anime/application/calendar_history.py`, `frontend/src/components/page/anime/CalendarReleaseCard.vue`.

Автоматические уведомления требуют присутствия аниме в коллекции, подтверждённой доступности серии в Kodik и CalendarRelease.aired_at строго позже UserLibrary.added_at, не позже текущего времени. Новая озвучка, поздний импорт и восстановленная дыра в выдаче провайдера не доказывают дату выхода. Неизвестная/будущая дата остаётся ожидающей; поздняя синхронизация календаря может разрешить отправку. Ровно в момент добавления серия считается старой. Повторное добавление использует дату новой записи коллекции. Подписка без коллекции сама по себе не отправляет автоматическое уведомление; ручные напоминания остаются отдельным пользовательским действием.

Блок главной «Новые серии» также использует даты выхода, а не разницу снимков Kodik: только доступные непросмотренные серии с added_at < aired_at <= now. Старые непросмотренные пробелы, неизвестные даты, будущие релизы и уже просмотренные/пропущенные новые серии исключаются. latest_episode, unwatched_count и next_episode считаются по этой выборке; кнопка просмотра начинает первую подходящую новую серию. Снимок episode_baseline, включая миграционный, не подменяет дату добавления. Даты календаря и прогресс читаются пакетно; коллекция и просмотренный прогресс не меняются.
