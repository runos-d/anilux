# Скрипт для автоматического добавления плееров

## Описание

Данный скрипт позволяет автоматически разместить плеер на всех страницах вашего сайта. Плеер будет отображаться только на тех страницах для которых он будет найден. Плеер можно легко настроить под ваши нужды. Даже если на своем сайте вы используете сложную верстку для вывода плееров, вы сможете настроить вывод плеера и на них не нарушив вид страницы.

Скрипт автоматически сортирует озвучки по последней серии и сезону. Таким образом изначально в плеере будет выбрана озвучка с самой последней серией. Эту логику можно изменить с помощью настройки приоритета озвучек. Также стоит учесть, что по умолчанию высокий приоритет имеют озвучки "Дублированный" и "Проф. Многоголосый" (это можно отключить настроив приоритет озвучек).

Для данного скрипта существует специальный раздел в базе, где вы можете следить за всеми найденными плеерами, а также скрывать ненужные или заменить определенные плееры на другие.

Скрипт может быть размещен без какой-либо настройки (просто возьмите код скрипта из генератора не изменяя никаких настроек). Даже в этом случае он будет в большинстве случаев находить и размещать плееры.

Для более простой и безошибочной настройки скрипта доступен генератор конфигурации.

Если же вам генератор не нужен, то тогда можете обратиться к описанию всех возможных настроек скрипта.

Для тех, кто по какой-то причине не может использовать у себя на сайте скрипт, а может использовать только iframe, сделана отдельная возможность пользоваться практическим всем функционалом скрипта через iframe. Главный минус iframe в том, что он будет показан пользователю в любом случае, даже если материал не будет найден. Код iframe также автоматически генерируются при изменении настроек в генераторе.

### Код скрипта (автогенерация на основе параметров выше):

**Копировать**

```html
<div id="kodik-player"></div>

<script>
  !function(e,n,t,r,a){r=e.createElement(n),a=e.getElementsByTagName(n)
  [0],r.async=!0,r.src=t,a.parentNode.insertBefore(r,a)}
  (document,"script","//kodik-add.com/add-players.min.js");
</script>
```

Плеер будет вставлен в div с id `kodik-player`. Сам же скрипт можно вставить в любое место на странице, если указано дожидаться загрузки страницы (стандартная настройка), либо же, если указано НЕ дожидаться загрузки страницы, то тогда скрипт можно вставить в любое место, но обязательно после элемента div, в котором будет выведен плеер.

Если скрипт по неизвестным для вас причинам не работает, то откройте страницу, на которой вы его разместили, в режиме просмотра кода (для этого нажмите правой кнопкой на странице сайта и выберите "посмотреть код страницы" ЛИБО добавьте `view-source:` перед адресом страницы). Далее на странице с кодом нажмите `CTRL + F` для поиска и введите `kodik`. Таким образом вы быстро найдете место, в котором находится размещенный вами скрипт. Теперь вы сможете сразу увидеть, правильно ли вставляются в скрипт данные или же вместо нужных данных вставляются ссылки итд. Если вам все равно ничего не понятно, то не бойтесь писать в поддержку.

### Код iframe (автогенерация на основе параметров выше):

Iframe вариант кода нужен только для тех, кто по какой-то причине не может использовать обычный скрипт. Iframe вариант менее гибкий из-за того, что плеер будет показан даже, если материл не будет найден. При использовании Iframe вам нужно будет те же самые параметры просто передавать в виде параметров URL

**Копировать**

```html
<iframe src="//kodikplayer.com/find-player" width="610px" height="370px" frameborder="0" allowfullscreen allow="autoplay *; fullscreen *"></iframe>
```

## Параметры

Параметры указываются в переменной-объекте `kodikAddPlayers`. Все параметры являются необязательными.

| Название | Стандартное значение | Доступные значения | Описание |
| --- | --- | --- | --- |
| `width` | `610` | `200`, `300px`, `80%` | Ширина выводимого плеера. Указывается в любом формате. |
| `height` | `370` | `200`, `300px`, `80%` | Высота выводимого плеера. Указывается в любом формате. |
| `onDomReady` | `true` | `true`, `false` | Дожидаться ли скрипту полной прогрузки страницы. Если этот параметр указан как `true` (стандартное значение), то скрипт можно поместить в абсолютно любое место на странице. Он в любом случае сработает. Но если вы хотите заменить плеер максимально быстро, то вам надо указать этот параметр в `false` и поставить сам скрипт сразу за кодом плеера (либо после него, но не до него). |
| `title` | Отсутствует | Название фильма | Если вы хотите передать скрипту название фильма вручную (в большинстве случаев это не имеет смысла), то можете вставить его в этот параметр. Вставлять сюда можно как обычное название, так и оригинальное название или другое название фильма. |
| `year` | Отсутствует | `0000` - `9999` | Если вы не можете передать ID КиноПоиска, то передача года тоже может увеличить точность распознавания. |
| `kinopoiskID` | | `123456789` | Поиск по ID КиноПоиска. Если указать скрипту любой ID (КиноПоиска, IMDb и т.д., то поиск будет происходить только по ID, параметр `title` учитываться не будет) |
| `imdbID` | Отсутствует | `"tt123456789"` | Поиск по ID IMDb |
| `worldartAnimationID` | Отсутствует | `123456789` | Поиск по ID World Art в разделе аниме (У World Art есть разные разделы материалов, в каждом из которых свои независимые ID) |
| `worldartCinemaID` | Отсутствует | `0` - `999999999` | Поиск по ID World Art в разделе кино |
| `worldartLink` | Отсутствует | Ссылка на world art | Поиск по полной ссылке World Art |
| `shikimoriID` | Отсутствует | `"123456789"` | Поиск по ID Shikimori |
| `replaceDomains` | Отсутствует | `["site1.com", "site2.com"]` | Список доменов других плееров, которые будут заменяться при нахождении скриптом плеера. |
| `onlyTranslationID` | Отсутствует | `[714]`, `[714,720]` | ID переводов, которые будут участвовать в поиске плеера. ID всех переводов можно получить через API ресурс `/translations` либо на странице списка озвучек. |
| `translationType` | Отсутствует | `"voice"`, `"subtitles"` | Типы переводов, которые будут участвовать в поиске плеера. Позволяет искать только по голосовому переводу или только субтитрам. |
| `types` | Все типы | Фильмы: `foreign-movie`, `soviet-cartoon`, `foreign-cartoon`, `russian-cartoon`, `anime`, `russian-movie`<br>Сериалы: `cartoon-serial`, `documentary-serial`, `russian-serial`, `foreign-serial`, `anime-serial`, `multi-part-film` | Типы материалов, которые будут участвовать в поиске плеера. Указываются строкой, через запятую. |
| `prioritizeTranslations` | `[704,734]` | `[123,123,"voice"]` | Повышение приоритета определенных озвучек. ID перечисляются через запятую. Чем "левее" ID, тем выше его приоритет. ID всех озвучек можно получить на странице списка озвучек. Стандартно повышаются приоритеты озвучек "Дублированный" и "Проф. Многоголосый".<br>Чтобы отключить стандартную приоритизацию, нужно передать значение `0`. Вместо ID также можно указывать тип перевода (`subtitles`/`voice`). |
| `unprioritizeTranslations` | `[800,882,"subtitles"]` | `[123,"subtitles",123]` | Понижение приоритета определенных озвучек. ID перечисляются через запятую. Чем "левее" ID, тем ниже его приоритет. ID всех озвучек можно получить на странице списка озвучек. Стандартно понижаются приоритеты озвучек "Украинский", "Субтитры" и "English".<br>Чтобы отключить стандартную приоритизацию, нужно передать значение `0`. Вместо ID также можно указывать тип перевода (`subtitles`/`voice`). |
| `blockTranslations` | Отсутствует | `[123,123]` | Удаление определенных озвучек из результатов поиска. ID перечисляются через запятую. ID всех озвучек можно получить через API ресурс `/translations` либо на странице списка озвучек |
| `camrip` | Отсутствует | `true`, `false` | Если указать `false`, то в поиске будут участвовать только материалы с качественной картинкой. Если указать `true`, то наоборот, будут искаться только камрипы. Если не указывать параметр вовсе, то искаться будут все материалы. |
| `notBlockedForMe` | `false` | `true`, `false` | Если указать данный параметр в `true`, то пользователю не будут выводиться плееры, которые заблокированы в его стране (страна определяется автоматически). |
| `blockInCountries` | Отсутствует | `"RU"`, `"RU,UA"` | Для того, чтобы полностью отключить показ плееров в определенных странах, добавьте их коды в этот параметр через запятую. |
| `foundCallback` | Отсутствует | `function (data, link) {}` | Тут можно задать свою собственную функцию, которая будет срабатывать, если плеер найден. |
| `notFoundCallback` | Отсутствует | `function (data) {}` | Тут можно задать свою собственную функцию, которая будет срабатывать, если плеер не найден. |
| `notExist` | `false` | `true`, `false` | Если данный параметр указан в `true`, то плеер будет добавлять скриптом только в том случае, если на странице нет других плееров kodik. |
