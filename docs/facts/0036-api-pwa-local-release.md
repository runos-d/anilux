Рабочий localhost:8080 использует собранные образы backend cf74be9ad4a8 и frontend 21881fb3c9ee. Девять миграций применены ранее; backend, worker, beat, post_media_worker и frontend пересозданы с сохранённой VAPID-парой. Последующее обновление frontend исправило подготовку файлов и перезагрузку первого PWA-клиента. Повторная проверка интерфейса исправила выравнивание, сенсорные элементы, окна, вложения редактора и обработку отменённого запроса каталога. Исправление по сообщению пользователя восстановило роль владельца, включило сохранённую группировку, обработало первое нажатие просмотра/вкладок и ограничило автоматические уведомления датой выхода после добавления в коллекцию. Отдельное исправление блока главной «Новые серии» применяет это условие к карточкам, счётчикам и номеру начала просмотра (docs/HOME_NEW_EPISODES_FIX_2026-10-13.md). Последним обновлениям миграции не требуются; проверки схемы и здоровья сервисов успешны.

Миграции проверены на копии рабочей MySQL с сохранением 177370 существовавших записей, прежнего прогресса и состояний подписок. Перед переключением остановлены записывающие сервисы и сохранены согласованные cutover-database.sql/cutover-media.tar в backend/data/local_release/pwa-release-20261013-092218; прежние образы имеют теги rollback-20261013.

На запущенном сайте подтверждены 20 проверок PWA, офлайн-оболочка/каталог, нативная возможность установки Chrome, системный Kodik PiP и зашифрованная доставка рабочего Celery при закрытых страницах приложения. Временные аккаунт/подписка/уведомления удалены. Старой версии требуется закрытие вкладок для смены worker; последующие версии используют кнопку обновления. Выпуск локальный; физическая телефонная приёмка и публичное переключение не выполнялись.
