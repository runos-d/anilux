На основании запроса пользователя от 2026-10-15 выбран Django-рендер содержимого с общей JSON-проекцией для Vue. Варианты по User-Agent запрещены. Автоматические фасеты и управляемые сочетания индексируются от 5 доступных тайтлов; студии и страны не добавляются. HTML и метаданные проверяют живые права без общего кэша; индексирование включается явно только с настроенным публичным HTTPS origin. Это заменяет черновой выбор и конфликт порогов D0010/F0015.

Реализация и проверяемые границы: `docs/SEO_IMPLEMENTATION_2026-10-15.md`, `backend/apps/seo/tests.py`, `frontend/src/composables/useSeo.test.ts`.

Уточнение пользователя 2026-10-16: SEO не заменяет существующие страницы и интерфейс приложения. Самостоятельная упрощённая сетка каталога отменена. Подборки и их карточки должны использовать оформление каталога во всех темах (dark, polnochnaya, light), общую сетку, AnimeCard и общий футер. Проверять обычные сценарии UI и визуальную согласованность, а не только наличие метаданных.

Дополнение 2026-10-16: страницы подборок, включая /anime/browse, используют весь CatalogView (поиск, фильтры, сортировку, перемешивание, размер страницы и пагинацию), а не отдельную сетку. Условия года/жанра/сезона/типа/статуса/управляемой подборки остаются базовыми; дополнительные фильтры уточняют их. Заголовок с хлебными крошками и общий сгруппированный футер оформляются токенами текущей темы. Уточнения хранятся в URL и одинаково применяются серверным HTML и JSON-проекцией; поисковые варианты -noindex с canonical на базовую подборку.

Уточнение футера 2026-10-16: постоянные ссылки на разделы, документы и контактную почту, SVG сакуры; исключены зависимость от текущей страницы и ссылки на отдельные посты. Общий реестр для Vue и HTTP, без отдельного запроса футера. Существующий CSS сохраняется. Утверждённые юридические тексты и основной публичный HTTPS origin не выдумываются.
