# Файлы со всеми фильмами, сериалами, роликами

## Описание

Файлы созданы для удобного парсинга базы программами или скриптами.

Для парсинга всей базы рекомендуем вам специально предназначенное для этого API.

Данные файлы предназначены для тех случаев, когда невозможно воспользоваться API.

Информация в API обновляется в реальном времени, данные же файлы формируются раз в час.

Для запланированного парсинга: Если у вас есть возможность, то ставьте время парсинга не ровно в 15:00 (к примеру), а добавляйте еще какое-то количество минут (например 15:24). Тогда доступная вам скорость скачивания будет гораздо выше.

Информация из КиноПоиска доступна только в JSON файлах.

Для скачивания файлов необходимо в ссылке указывать ваш API токен: `?token=74ecb013335271e4344ebc994956dd75`.
