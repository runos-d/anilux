- Build Engineer - runtime, зависимости, образы и корневой .env.
- Release Engineer - Compose, миграции, preflight, локальная поставка и восстановление.
- Architect - REST/WS/worker, транзакции, события, IDs и границы внешних API.
- QA/Test Owner - изолированные регрессии, browser/transport и область доказательств.
- Process Owner - повторяемые backup/GC/restore и обновление документации.
- Quality Reviewer - повторяющиеся замечания о загрузке, превью, фокусе и стабильности UI.
