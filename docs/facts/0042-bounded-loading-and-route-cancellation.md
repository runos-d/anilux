Переход на другой route отменяет активные HTTP-запросы до выполнения auth guard. Обычные запросы имеют таймаут 20 секунд; пятиминутный таймаут оставлен только для FormData-загрузок. После мутаций Vue Query обновляет только связанные группы данных, а не все приватные запросы. Проверка непрочитанных чатов использует realtime-события, foreground refresh и страховочный интервал пять минут; опрос незавершённых постов выполняется раз в три секунды только при наличии такой публикации и раз в минуту в простое.

Библиотека, избранные аниме/темы/серии, списки плейлистов, элементы обычного и share-плейлиста отдаются ограниченными страницами. Детальная карточка плейлиста не сериализует весь состав перед отдельным запросом элементов; карточки списка загружают только три постера обложки. Поиск аниме в редакторе возвращает десять результатов на страницу и отменяет предыдущий ввод вместо передачи до 500 результатов. Случайное аниме выбирается индексным поиском в диапазоне ID без материализации всего каталога и имеет `no-store`.

Хронологическая extended-лента использует подписанный keyset-cursor и выбирает `page_size + 1` идентификаторов вместо создания снимка всех доступных постов. На рабочем локальном наборе прогретая первая страница из 20 записей заняла 146–149 мс, следующая -191,6 мс; пересечений ID между страницами нет.

Сборка не рекурсивно preload-ит зависимости route; редкие темы, навигация, эффекты, уведомления, push и chat runtime вынесены из критического бандла. Общие визуальные компоненты регистрируются асинхронно. На главной удалён N+1 из запросов деталей каждого показанного аниме, а четыре запроса Google Fonts объединены в один. Повторно используемые SEO discovery links кэшируются на пять минут с ключом ревизии каталога; измерение построения SEO для главной снизилось с 359,0 мс и 10 SQL на холодном кэше до 14,7 мс и 5 SQL на прогретом.

В итоговой контрольной production-сборке основной JS уменьшился с исходных 477,13 до 322,63 КБ (gzip с 162 до 115,18 КБ), основной CSS -с 285,87 до 69,49 КБ, PWA precache -с 3241,96 до 389,25 КиБ. Локальный browser profile главной зафиксировал 41 ресурс, два API-запроса, отсутствие ошибок консоли и FCP около 832 мс; запросов деталей аниме нет. Полный Vitest проходит: 63 файла и 174 теста; также проходят `vue-tsc`, production build, compileall, Django system check и проверка отсутствия незаписанных миграций. После выдачи приложению прав только на отдельную disposable-схему успешно прошли все 15 MySQL backend-тестов плейлистов.

Списки выбора пользовательского плейлиста теперь получают по 20 записей и имеют явную дозагрузку. Административные жалобы и пользователи, публичные плейлисты профиля и работы студии также ограничены страницами. Для публичной/пользовательской сортировки плейлистов и упорядоченного чтения их элементов добавлена миграция составных индексов `playlists.0006`.

Уникальные MySQL-ключи `SeoAlias.path`, `SeoHub.path` и `SeoOverride.path` ограничены 255 символами миграцией `seo.0003`, поэтому Django system check больше не выдаёт `mysql.W003`. Генераторы канонических путей ограничивают длинный anime slug без потери ID, для слишком длинного franchise slug используют стабильный ID, а сигналы не пытаются сохранять неиндексируемые legacy aliases.
