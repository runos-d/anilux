# Документация по API: /years

## API-токен

Ваш API-токен: `74ecb013335271e4344ebc994956dd75`

---

## Описание

Возвращает список всех возможных годов либо для всех материалов, либо для материалов отфильтрованных вашими параметрами. Учитываются только материалы, для которых прописан ID КиноПоиска.

Запросы отправляются по ссылке: `https://kodik-api.com/years`

---
